TESTS FONCTIONNELS - Les recettes de grand-mere
========================================================================

Liste des tests a rejouer dans le navigateur avant chaque livraison.
Cocher [x] devant chaque test qui passe.

AVANT DE COMMENCER
------------------
  1. Remplir le fichier .env (DATABASE_URL, ORIGIN, BETTER_AUTH_SECRET)
  2. npm run db:push
  3. Ajouter des ingredients en base (aucune page ne le permet) :
     INSERT INTO ingredients (nom) VALUES ('Poulet'),('Riz'),('Soja'),('Pommes');
  4. npm run dev   ->   http://localhost:5173

  Comptes utilises : Alice (alice@test.fr / motdepasse1)
                     Bob   (bob@test.fr   / motdepasse2)
  Ils sont crees par les tests 3 et 4.

  Recettes de reference, creees par Alice au test 40 :
     "Poulet au riz"  = preparation Marinade (Poulet) + preparation Cuisson (Riz)
     "Poulet roti"    = preparation Preparation (Poulet)
  Et "Riz saute" (Riz + Soja) creee par Bob, pour tester les droits.

[ ] 42 Saisir un ingredient avec une quantite mais sans unite.

[ ] 44 Apres creation, ouvrir /mes-recettes et /.
